E-commerce Marketing & Sales Funnel Analysis

SQL Case Study | Google BigQuery

Project Overview

This project analyses e-commerce customer activity using SQL and Google BigQuery to understand customer conversion, traffic sources and revenue performance.

The objective is to identify business insights that can help improve marketing effectiveness, customer conversion and overall sales performance.

Business Objectives

* Analyse customer activity across different sales funnel stages.
* Calculate conversion rates between funnel stages.
* Compare customer activity across traffic sources.
* Understand the time taken for customers to complete purchases.
* Evaluate revenue performance and average order value.

Tools & Technologies

* SQL
* Google BigQuery
* Google Sheets / Excel

## Key Findings

Based on the supplied revenue analysis:

| Metric | Result |
|---|---:|
| Unique Visitors | 5,000 |
| Unique Buyers | 826 |
| Purchase Events / Orders | 826 |
| Total Revenue | $87,975.11 |
| Average Order Value | $106.51 |
| Revenue per Buyer | $106.51 |
| Revenue per Visitor | $17.60 |
| Visitor-to-Buyer Conversion | 16.52% |

Business Recommendations

1. Use revenue per visitor to evaluate acquisition performance.
2. Identify customer drop-off points in the purchase funnel.
3. Experiment with product bundles and upselling to improve average order value.
4. Analyse repeat purchases and customer retention.

Project Limitations

The supplied results currently confirm revenue metrics. Funnel-stage counts, traffic-source comparisons and conversion-time results require additional query exports.
