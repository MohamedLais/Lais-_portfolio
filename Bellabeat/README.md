Bellabeat: Smart Device Usage & Growth Opportunities

Google Data Analytics Capstone Case Study

⸻

Project Overview

An exploratory data analysis of Fitbit fitness tracker data to understand daily activity, consumer behaviour and sleep patterns. The project identifies opportunities for Bellabeat to improve its wellness app and marketing strategy.

Tools & Technologies

* Microsoft Excel
* Data Cleaning
* Exploratory Data Analysis
* Data Visualization
* Statistical Analysis

Methodology

The project follows Google’s six-stage data analytics process:

1. Ask – Define the business problem.
2. Prepare – Understand the dataset.
3. Process – Clean and prepare the data.
4. Analyze – Identify trends and patterns.
5. Share – Present findings through visualizations.
6. Act – Develop business recommendations.

Key Findings

| Metric | Result |
|:--|--:|
| Cleaned Daily Activity Records | 1,373 |
| Distinct Activity Users | 35 |
| Average Daily Steps | 7,247 |
| Median Daily Steps | 6,910 |
| Average Sedentary Time | 993 min/day |
| Average Lightly Active Time | 185 min/day |
| Average Fairly Active Time | 14 min/day |
| Average Very Active Time | 20 min/day |
| Average Recorded Sleep | 419 min (6h 59m) |
| Users with Sleep Records | 24 |
| Steps & Calories Correlation | +0.59 |
| Steps & Sleep Correlation | -0.18 |

Business Recommendations

* Introduce personalised daily activity goals.
* Encourage movement through smart reminders.
* Improve sleep tracking and weekly wellness summaries.
* Test engagement strategies through controlled experiments.

Limitations

The dataset uses historical Fitbit data from 2016 and a relatively small sample. Findings should be validated using Bellabeat’s own customer data.
